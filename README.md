# Radar BOE Express

Prueba pública de validación comercial de un radar independiente de licitaciones.

## Qué hace

- Consulta fuentes oficiales del BOE.
- Detecta anuncios de licitación del día.
- Extrae valor estimado y plazo cuando están publicados.
- Presenta una muestra ordenada y enlaza siempre a la fuente oficial.

## Estado

Esta versión es una prueba beta de demanda. No es un servicio oficial del BOE ni sustituye la revisión de anuncios y pliegos.

## Acceso beta

Usa la plantilla de issue **Solicitar acceso beta**. No publiques datos sensibles ni credenciales.
